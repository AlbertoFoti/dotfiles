# dotfiles

Personal configuration files.

## Neovim

The Neovim configuration lives in [`nvim/`](nvim/). Link it into `~/.config`
with:

```bash
./sync_nvim_conf.sh
```

This command replaces any existing `~/.config/nvim` directory. See
[`nvim/README.md`](nvim/README.md) for prerequisites, language support, and the
keymap guide.
